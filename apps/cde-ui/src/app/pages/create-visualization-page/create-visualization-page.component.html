Create a distance visualization

Upload 2D or 3D cell data, choose the anchor cell type, and explore the distance from every cell to the closest anchor cell.

Step 3 of 6: Configure parameters

Distances are measured from each cell to its closest cell of the anchor cell type, in a straight line (Euclidean distance). The anchor cell type is "Endothelial" by default, or the first cell type when the data has no "Endothelial" cells.

Distances longer than the distance threshold aren't shown or counted.

Pixel size converts coordinates to micrometers. Enter 1 if the coordinates are already in micrometers.
