Watches what decides whether theme colors resolve to their light or dark values: the system color scheme preference, the color-scheme of the document's root element, and the theme picked with the visualization's theme switch. Must be called in an injection context.

setUpChartTooltips
setUpChartTooltips(view: View)

Sets up a chart's tooltips. After each tooltip update, the tooltip element:

  • Moves into the overlay holding the chart, such as a fullscreen view, or back to the body. vega-tooltip appends its element to the body, but CDK overlays open in the browser's top layer, which covers the rest of the page whatever its z-index.
  • Takes the chart's font. The body is outside the app element that holds the theme's font tokens, so the tooltip can't read the font from the stylesheet.
Parameters :
Name Type Optional Description
view View No

Vega view using vega-embed's tooltip handler
Returns : void
